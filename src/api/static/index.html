xtctx — running

This is the xtctx API server. xtctx is a CLI-first cross-tool context continuity tool — the interactive surface lives in your terminal.

CLI cheat sheet

xtctx statusone-screen runtime summary
xtctx context recent --watchlive tail of recent sessions
xtctx sync --diffpreview tool-config writes
xtctx ingest --fullfull re-scrape across tools
xtctx serverun API + MCP server (this process)

MCP tools

AI assistants connect to xtctx via the MCP server (stdio transport) started by xtctx serve. The handoff surface — three tools — is the primary user-facing API: xtctx_recent_sessions, xtctx_session_detail, and xtctx_last_session_brief. Operational tools (xtctx_continuity_status, xtctx_effective_policy, xtctx_list_configs, xtctx_get_config, xtctx_tool_preferences) are also available.

For project-lifetime knowledge (durable decisions, multi-agent shared memory, cross-domain knowledge graphs), pair xtctx with construct.
