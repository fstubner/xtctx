xtctx — running

This is the xtctx API server. xtctx is a CLI-first cross-tool context continuity tool — the interactive surface lives in your terminal.

CLI cheat sheet

xtctx statusone-screen runtime summary
xtctx context recent --watchlive tail of recent sessions
xtctx knowledge lslist saved decisions, gotchas, FAQs
xtctx sync --diffpreview tool-config writes
xtctx ingest --fullfull re-scrape across tools
xtctx serverun API + MCP server (this process)

MCP tools

AI assistants connect to xtctx via the MCP server (stdio transport) started by xtctx serve. The recall surface (xtctx_search, xtctx_project_knowledge) and the writeback surface (xtctx_save_decision, xtctx_save_error_solution, xtctx_save_faq) are available there.
